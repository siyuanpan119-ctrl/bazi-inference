# v0.3.0 开发复盘：评分、执行问题与假说

本文件只发布汇总与通用方法，不含命例出生资料、敏感生平、题目、逐题答案或私人提交。

## 原答卷表现

2026-09-06核对一套答案公布前已提交首选的40题、8个命例：答对15题，全部40题均作答，正确率37.5%。各命例命中数为1、3、1、2、2、2、3、1（每例5题）。第二选择仅可作定位排序问题的诊断，不加进首选得分。

按出题者标注的方法分组，八字来源20题中答对6题，紫微来源20题中答对9题；当时实际推演均采用八字。这是小样本、混杂的事后分组，不能证明任何方法优于另一方法，也不能断定错误主要因为未使用紫微。

四选一均匀随机的期望命中为10/40。事后观察到全部固定选C会得到14/40，只能说明本套题选项分布偏斜，不是事前登记的基线，不将其用作下轮猜题规则。每人的题目相互关联，不能按40个独立样本夸大证据。

原首选字母可以核对，但旧记录的候选原子项为空泛占位，证据集合为空；只冻结了候选卡而非完整技能与宿主设置。外部答复中展示过哈希，本轮补登记了该引用；程序不把补登记称为既有独立时间戳。因此该成绩是**已提交首选的真实分数和探索性基线**，不是经过完整控制的技能效果实验。

## 实际错误与通用改动

| 执行缺口 | 本版如何改变普通推演 |
|---|---|
| 仍以一个配偶星、合或冲决定年份 | 各候选同看原局、大运、流年，区分共有背景与首选独有条件 |
| 从结构存在跳到登记、离异或特定生平 | 固定现实进程；一条主题支持不代表复合选项全部成立 |
| 事件主体未分清 | 先比较本人、配偶、父母等主体的独有线索，日支不机械等同配偶 |
| 收入能力升级成资产金额、学习主题升级成学位 | 分开流量/存量、机会/完成、资格/岗位；不补未知细节 |
| 前题猜测进入后题前提 | 题干事实、计算结果和候选结论分开；联动须比较候选组合 |
| 模糊地点和时段被压成精确输入 | 保存原始表述，明确情景；变化的分支完整重建与比较 |
| 交运年和多年阶段被一条关系代表 | 按实际大运区间切段，区分运行日期和历史命题观察日期 |
| 无证据记录却表示较高信心 | 不从哈希或计算底稿推断可信度；解释状态不冒充概率 |

以上改动来自已知答案后的执行审计。没有为每个答案新编一条“应验口诀”，也没有把偶然猜中罕见故事、中奖叙事视为有效规则。

## 紫微新增能力及其范围

新增固定版本本地排盘适配器，以及命身、主辅曜、三方四正、分层四化、岁限叠宫和事项比较教学。八字和紫微分别先形成判断，再按事前固定的规则比较新增条件；一致不自动增信，冲突不临时选派。

紫微安星和八字节气月、起运不混用；软件没有出生城市参数，历史时制校验仍在上游。默认取法与晚子替代口径分别保存。新模块的软件正确性与人生预测有效性是不同验证目标。

本次检索未找到足以证明八字与紫微融合能提高这类具体事件命中率的可靠研究。2018年一项243名大学生、3位命理师的硕士论文，公开摘要报告紫微判读与人格、家庭关系量表总体无显著相关，少量分组为低度相关；仅阅读公开摘要，不将这个有限样本外推为所有规则均被否定。[论文摘要](https://www.airitilibrary.com/Article/Detail/U0003-1807201810474500)。

## 下一轮怎样检验，而非宣布成功

按新人物留出；同一批未知答案分别运行旧版八字、新版八字、新版八字＋紫微，另保存紫微原排序以诊断融合。事前固定完整技能内容、引擎及取法、宿主模型与设置、同一输入和评分规则。模型设置不可得时如实标不可严格比较，不填猜测值。

比较全题首选命中、覆盖率，以及组合把旧答案改对几题、改错几题。保留弃答与失败，不能通过缩小分母宣布准确率提升。旧40题已经用于开发，不能拿它们重新选答案来计算新版预测率。操作见[multi-method-trial.md](multi-method-trial.md)。

# 复盘与准确率验证

仅在用户要求对答案、复盘、提高准确率或维护技能时加载。普通算命依主文件与领域方法解读，不执行评分或实验流程；选择题交付见 `exercise-mode.md`，结构化评测再用 `decision-record.md`。

## 长期优化目标

用户已明确本技能主要面向普通用户，目标是改进可迁移的命理推演技巧与实际解读能力。多轮题目与复盘是验证工具。保持这一方向：普通咨询无需选项也能形成主要判断；题卷完整、记录齐全、语气谨慎或分级变化只证明流程改善，不能替代预测表现。

每轮先辨明修订对象：排盘计算、命局取法、作用对象、岁运应期、解释范围，还是题型交付。前三类及应期的修订回到通用推演文件；题号、答案表、计分及检查器流程留在本模块和 `exercise-mode.md`。同一失误优先修正已有规则的执行条件，不为每道错题增加一条普遍禁令。

## 一、冻结原始提交，再对答案

1. 保留揭晓前的题干、候选、出生输入、观察时点、技能版本、排盘口径、原首选、原备选、依据及当时的把握标记。原记录缺字段就标缺失，不根据正解补写成事前判断。
2. 同一命例使用稳定的命例标识；题号只在本轮答卷内定位，不进入通用推断规则。
3. 按原首选逐题计分，并展示错题的“原选项→标准选项”。揭晓后的改选、事后新增的备选均不计原始命中。
4. 标准答案有缺失、对应错位或题面歧义时单列；不静默删除难题改变分母。说明计分口径，保留可以核验的原成绩。
5. 用户提供的标准答案是本轮评分依据，不自动成为经过核验的完整传记。多子句选项被判正确，也不能据此确认其中每一句现实叙述或命理公式。
6. 题面公式若与已核验五行生克或历法事实冲突，保留纠错；不得改公式迎合答案。选项字母计分与题面争议分别报告。

遵守本轮“不联网、不搜题、不找记忆答案”等限制。复盘使用已提供题目、标准答案与原底稿；不得检索相似生日、旧命例答案或历史记忆补出推理。当前工作记录可用于核对自己当时实际写了什么。

## 二、查错误发生在哪一步

先检查执行，再考虑新增传统规则。允许一题有多个原因，但每个归因都须对应原记录中的具体缺口；不能凭已知正解猜测错误原因。

| 错误类型 | 核查与处理 |
|---|---|
| 输入或题目映射 | 查原图/原文、出生信息、题号选项与观察时点；有可定位的录入错误才修正 |
| 排盘或时间口径 | 按 `calculation.md` 复算并给出差异；需要实证计算错误才能归因，不能因选错就改时辰、日界或起运口径 |
| 判断目标错位 | 对照题目主体、事项阶段、时段；例如收入与净资产、关系机会与登记分开，回到 `event-discrimination.md` |
| 共有背景冒作区别 | 查同一条件是否同样支持别项；撤去虚假的区分作用，保留为背景，不靠换措辞增加证据 |
| 候选遗漏或审查不对称 | 查是否实际阅读每个候选、使用同一主线并检查救应；复制总述不算逐项比较 |
| 排序错误 | 正解已在事前备选中时，查首选为何排在它前；区分无依据排序、漏反证及时间分支未落实，不把备选算命中 |
| 纯猜测或细节不可区分 | 保留原猜测状态；猜中不能自证规则，猜错也不能反证一个从未实际采用的规则 |
| 题面或评分问题 | 选项互含、公式错误、答案对应不清分别记录；不因答错就宣称标准答案错误 |

底稿还需人工核对首选、最强备选、候选比较文字及最终答卷是否一致。检查器只能查部分字段与引用，无法保证自然语言比较有效。正解未进入原备选，优先复查整个候选比较；正解原已在备选，优先复查最终排序，两者均不能预设只需换一个权重。

## 三、把修订写成可撤回的规则

优先定位可迁移的判断环节：旺衰与格局是否混淆、根气和作用通路是否成立、六亲对象是否固定、大运是否支持、流年改变了哪个必要条件、救应是否足以维持原有作用。只有交付层出错才修改题型流程。多处同时修复时分别说明，不把综合变化归功于某一模块。

对会改变首选的新增或改写规则，至少记录：

- 来源层次：计算事实、声明的传统取法或技能操作假设；来源口径依 `knowledge-sources.md`，不能假托古籍。
- 固定前提：适用主体、事件阶段、时间范围、取象和承接条件；哪些场景不适用。
- 可检验区别：相对哪个竞争解释多满足什么条件，哪些仅为共有背景。
- 反例与撤回条件：出现何种条件应减弱、保留并列或撤回首选；未知条件不得当反证。
- 验证状态：由哪些已见案例提出、是否已在未参与修订的新命例上检验；无新验证就标“待检验假说”。

新增技巧先作为有前提的待验证假设：用一个有代表性的反向条件检查它是否可能作出不同判断，再放入未参与修订的新命例试用；未经验证不写成一遇某星某冲就必然发生某事的规则。一题解释得通不足以升级为通用规则。不把本轮题号、生日、年份答案、人物故事或成绩编码进技能；不在揭晓后临时换六亲指代、合化条件或流派来凑正解。更强的语气、更多术语和更完整的记录均不等于更高命中率。

## 四、用新命例比较版本

将已揭晓命例用于定位缺陷，将未揭晓命例留给修订后的验证。先完成并固定版本、待验证的判断变化和评分口径，再接收新题答案；解答期间不为让解释更顺而继续调整规则。有限的新样本可用于同批旧新版隔离比较，无需为了反复修改耗尽验证集。隔离可减少本次上下文互相影响，不能保证公开命例从未进入模型训练。

已揭晓的命例用于复盘与检查旧问题是否再次出现；重新答对不计提准证据。训练、调参、校时用过的命例整组退出新的独立验证，包括同一人的其他问题与改写题。

旧版和新版在同一批未揭晓答案的新命例上分别完成答卷并冻结，再统一揭晓评分。两边使用相同输入、候选、计算口径和允许资料，各自不得看另一份答案。若上下文无法隔离，应说明限制，不声称已经独立。公开题目可能存在训练数据污染；换新线程不能保证从未见过题目，优先使用未公开且答案由独立来源预先固定的命例，并如实说明来源局限。

版本比较默认使用简短原始记录，只有显式结构化审计或机器评测才启用v3。每版分别汇总两系统初选与合参的改对、改错；不要事后选成绩最高的体系拼成一份答卷。一次运行中的版本差异还包含执行上下文与模型选择变化，不能把每个改对都归功某条规则。

### 检查方法能否脱离选项使用

在新的验证命例中加入无选项阶段：只提供出生资料、必要现实背景、观察时点和开放问题，让执行者先形成有主次的判断，记录对象、方向、阶段或窗口及改变判断的条件；冻结后再提供选项，检查原判断是否已经覆盖所选含义。不要把所有领域、相反事件或所有年份都列出来充当覆盖。

只有在第一阶段实际没有接触选项和答案时才称无选项预判。能用独立上下文时传入最少原始资料；当前上下文已经见过选项或答案，就不能靠一句“忽略它们”恢复盲测。已给背景不是预测命中，后加解释不是原先已作出的判断。

同时查看预测的具体度与范围：描述过宽、方向相反也都列出、不断改变窗口的判断不能因为后来相容就算准确。题目正确但原预判没有对应内容时，只计选项阶段成绩，不计开放解读成功。普通用户咨询的反馈可用于复盘，但只有独立、事前固定的事实与评分口径才能用于准确率评估。

无需普通用户执行实验流程。没有新题时先完成可复核的修订，明确尚未验证准确率；不索要新题作为完成技能修改的前置条件。

| 指标 | 统计口径 |
|---|---|
| 首选命中率 | 正确首选数/可按约定评分的题数；漏答单列，不能作为提高命中率的删除项 |
| 备选覆盖率 | 正解进入揭晓前首选或已登记备选的比例；仅定位候选搜索问题，不替代首选成绩 |
| 猜测率与猜测命中 | 使用事前标记，报告数量和成绩；不能事后把猜中升级为有依据判断 |
| 题型表现 | 年份、职业、关系等按事前统一分类，同时报告题数，避免小类少量题被夸大 |
| 把握分层 | 按事前固定的相对依据/条件敏感/猜测等等级报告实际命中；未经独立校准不把等级换成概率 |
| 命例层面 | 同时报告命例数、每例成绩及总体题数；同一人的多题相关，不能当成等量独立命例 |

依据类别和它覆盖的子项一同冻结。仅有相容线索的猜测与全无区分依据的猜测分别统计；局部有倾向、完整选项仍不确定时保留两层记录，不在评分时改写原类别。比较分组成绩时同时看题型、具体度和命例组成，不能因猜测组某次更高就主张随机选择，也不能仅凭有术语依据便宣布另一组更可靠。没有预先固定的分类须注明事后整理。

报告旧新版在同一新命例上哪些改对、哪些改错及净变化，保留不利结果。需要不确定性估计时以命例为分组单位，不把同例多题当独立样本；样本少时只报描述性成绩，不承诺稳定提升。

八字、紫微、合参分别冻结答案并评分。合参依 `ziwei-inference.md` 使用真实区别；不得因同票增加信心，不以任意权重凑最佳成绩。任何权重或阈值若经已见样本调整，须在另批新命例验证。

## 五、报告实际验证了什么

程序测试、检查器及自编合成例可验证字段一致、分支覆盖、完整作答和规则执行，不能验证命理有效性。答案独立、揭晓前冻结的现实命例比较才能提供这批任务的命中表现，仍不能仅凭少量选择题推及现实诊断、寿命或其他事实预测。

复盘输出先给原始成绩与主要错误，再给具体修订及验证状态。分别说明“执行缺陷已修复”“候选排序假说待验证”“新命例成绩是否改善”，不将其中一个结论代替另一个。

选择后续维护版本时，保留可复核的计算修复、通用推演和可用接口，精简重复或与日常咨询无关的强制流程；无新验证的规则只作操作假设。维护推荐与准确率排名分别报告，没有表现优势就不称某版最准确。检查器的结构合法、仍待复核及实际语义缺口如实披露，不能通过放宽检查或补造引用宣布修复。已揭晓样本只作回归材料，最终维护版仍可更新，但不得靠重做这些样本提高对外准确率声明。

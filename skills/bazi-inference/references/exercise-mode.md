# 命例选择题与评测入口

仅在用户提交选择题、要求完整答卷或进行命例验证时读取。普通咨询、无选项年份比较和八字紫微合参沿用主文件及领域方法，不触发题卷审计。

## 先推演，再映射选项

先从原文或原图核对出生资料、题号、所问主语及选项，再开始解释。每题在本次底稿保留问题原句；数量、亲属指代、否定词和年份照原文，转录或压缩后对回原件。只有具体事件日期未知时才按区间处理，不靠熟悉的命例叙述补字。随后采用 `inference.md` 和 `question-analysis.md` 的同一主线，不为选项换六亲、格局、喜忌或合化条件。

固定题干事实与未知变量。已给事件只问年份时，仅比较年份；已给地点或职业领域时，该背景不能作为某个选项独有的支持。跨题推定矛盾前回查原题的主体、时态和措辞；自己的前题选择仍是判断，不能作为后题已知生平。

若题面已经可见，如实称为“看过选项的分析”。真正无选项的预判须在选项不可见的独立阶段冻结，不能事后声称自己未见选项。维护时的两阶段验证见 `review-and-evaluation.md`。

每题按主体、事项阶段、时段和附带细节拆开，保留候选的原量词、否定范围和截止时间，不将“目前未婚”扩成“终身无伴侣”。依据 `event-discrimination.md` 的同尺度及替换检查，有同类候选时先审其中最强的竞争解释，再比较其他候选。不能只排除异类事件，就默认财务或关系类中的某一项胜出；也不能给首选的宽泛主题记支持，却用备选的精确细节未知否定它。

## 完整作答与把握

用户要求答题时，默认每题给一个最终首选，先交答案表，再说明主要依据和必要的备选。资料或作用比较尚未完成时，按 `event-discrimination.md` 补查后再定答案，不提前把未做的分析称为猜测。完成相关分析仍难分时照常给字母，明确猜测，不要求用户再授权单选。

最终选择、相对排序与事实确认分别处理：

- 有实际条件差异，可保留排序；说明差异支持的是方向、应期还是细节。优势弱或对条件敏感时称“低把握倾向”，未知子句照样保留；不把完整命理解释当作完整选项已得到支持。
- 只有共同主题、核心区别仍未知时，保留并列，仍提交一个首选；按 `event-discrimination.md` 的依据状态说明“线索未分出优劣”或“无区分依据”。前者记录实际使用的命理线索及其局限，后者承认所选字母没有命理上的优先依据。非命理的语义排除须另说来源，不能包装成命盘所示；字母顺序、常见故事或随机数也不能冒充命理理由。用户要求只交字母时在底稿保留这些区别，不再用“押测”统称。
- 不因未知细节就否定整个候选，也不因支持一个子句就证明复合选项全真。短选项、普通故事和原首选都不享受优先。
- 同一标准用于所有题型。交卷前固定依据类别及它覆盖的子项，不能让一处细节未知把所有题批量降成无区别，也不能让一处方向相容把整项升级。依据类别未经校准不当作概率或可靠性等级，不把猜中事后改标高把握。

任务适用性按 `question-analysis.md` 的现实边界处理。历史题字母不构成医学诊断、犯罪指控或现实敏感属性事实；不能用“练习”标签规避这些边界，也不由某关键词整题弃答。

## 默认保留简短原始记录

成组命例和新旧版本答卷默认使用简短逐题文本；批量或合参本身不触发 JSON。每题保留：**目标与已知背景；主选；最强竞争解释（同类优先审查）；真正差异或仍未决之处；改选理由（如有）；必要的出生、历法或时间分支。**这些内容来自当时实际分析，不要求固定格式或人为凑出差异。整例的共用盘面可以统一引用，逐题判断须各自可辨。

各阶段完成实际比较就保存，再进入合参；改选保留原判断和新增区别，最终答卷与旁注一致。版本比较分别固定原答卷，不互借结论；若顺序分析看过前一结果，说明这一限制。不要先冻结字母，再把整批总述复制成逐项依据；仅改标题或批量留空引用不算完成审查。

需要分支时，记录各自计算及结论变化；只写实际完成的分支。候选年份是待比较对象，不能把不同候选年的任意片段当作同一观察时刻。未知细节如实保留，不为减少猜测题数补造支持。

只有用户明确要求**结构化审计或机器评测**时，才使用 `decision-record.md` 的现有 v3 JSON 和 `scripts/decision_record.py`；不另建简化 schema，也不降低检查标准。检查合法不等于排序有依据。区分尚未完成的计算、比较或引用工作，与分析后仍不可区分的事实；前者补齐，后者保留未知并提交标明猜测的首选。

## 交卷核对

核对题号总数、最终字母、把握标记与正文一致，备选不计首选命中。选项互含、错字或生克公式错误单列，不改原题凑答案。已知答案后的处理改用 `review-and-evaluation.md`，不得重写原答卷充当提准。

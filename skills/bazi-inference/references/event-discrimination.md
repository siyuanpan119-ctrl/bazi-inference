# 事件进程与应期判断

在用户询问具体变化、原因、时间窗口或多个年份时使用。先依 `inference.md` 核定原局与岁运，再把作用解释到用户所问的阶段。本文服务普通咨询；选择题的交付和评测格式另见 `exercise-mode.md`。

各领域的阶段划分是技能操作假设，传统依据为 `knowledge-sources.md` 的 TXT-ZPZQ、TXT-DTS、TXT-SMTH-DY 及 `ziwei-inference.md` 的星宫框架。它们不是古籍中的现代事件公式，也不是已校准的预测规律。

## 从作用变化形成主要判断

用简短底稿回答四件事，通常不需专门表格：

1. **条件与目标**：固定已知条件、本人或六亲、未知变量与时间范围。已给事件只问年份时，比较各年对该事件的承接，不重新要求证明已给地点、身份或事件本身；事件是否发生尚未知时，先比较发生、未发生及其他表现。截止某时的状态不扩成终身经历，程度描述不扩成每年皆如此。
2. **阶段基础**：原局及该段大运中，所问事项正在依靠哪条路径，哪里有瓶颈？先保留实际已有的节点、配合与状态。
3. **新增变化**：流年重现了什么，另新增、补齐、削弱或解除什么？对同一环节比较支持与牵制，判断其还能否发挥，不把原有关系直接当新触发。
4. **结果与竞争**：先写作用链实际改变的功能，如输出更易兑现、支持来源受限、共同责任增加；再沿“功能变化→现实活动（已知或条件情景）→本期维持/改变的环节→待判断结果”说明主次。将每条依据接到它实际支持的那一环，未接上的环节保留未知。定位到某人的星宫只改进主体判断，不同时证明发生何事。

可复算的符号、传统作用链和现实事件的确定性分开。用户已经给定的经历只界定分析范围；相对方向有区别时保留主次，精确细节未知只限制该细节。

### 让判断停在实际得到支持的环节

沿用同一主线，对照所问阶段选择适当的结论，不从格局名称直接跳到人物履历。以下是操作假设，用于约束解释范围，不能当作现代事件的命理定律。

| 已核验的作用变化 | 可优先比较的功能 | 进一步判断完成结果时要区分 |
|---|---|---|
| 印的来源与生身路径可用，食伤表达有承接 | 学习方式、训练支持、考核产出 | 支持出现、持续修读与取得学历；没有完成区别时保留能力方向 |
| 食伤到财、财到日主的承接改善 | 交付、收费或回款条件 | 工资、交易、自营的来源，以及收入、成本、偿债和留存 |
| 配偶作用或夫妻宫支持仍可发挥 | 互动、协商或共同责任的维持条件 | 支持现任关系、亲子合作还是新接触；支持尚存不证明婚姻法律状态 |
| 岁运冲合改变原有根、中介或来源 | 原功能增强、减弱、改道或恢复 | 对所问事件的哪个阶段有作用；变化强烈不自动早于、重于或更接近事件完成 |

对每条支持再问其适用范围：若它同样支持岗位变动后的重新就业，就不能单独用于排除失业；若它同样支持分开后的共同照顾，就不能单独用于排除离婚。对不利作用也作同样检查。使用现实背景缩小范围时，明确该背景由用户给定；没有背景仍给当前最有依据的方向或条件判断，不索取待预测结果。

### 比较两种表现时，用同一把尺

把主判断与最接近的竞争解释放在同一主体、阶段、时段和细度比较，保留两者原本的量词与程度。先判断事件领域，再比较同领域中的来源、活动与结果：已经偏向财务压力，还须比较负债、经营损失和投资损失，不能只胜过另一个领域便确定其中一项。对各方检查实际支持、反向与未知；已承认的竞争支持要进入排序，不能因它不是首选而忽略。

用一次替换检查：**把主理由中的结论换成最强竞争表现，理由是否仍然成立？** 成立时，将该理由降为共有背景，并用剩余条件重新排序；不能只写“对方也可能”而维持未经支持的领先。若撤回了题意补充、作用路径或某个年份的论证，同步撤回依赖它的排序，再审剩余支持。撤回旧论证只取消旧优势；提出新主案仍需说明自己的区别。若两边剩余依据未分出优劣，保留竞争状态，不将改口本身称为推演改进。

先判断两种表现是否可以同时成立。活动能力仍在与暂时没有岗位、资源周转改善与心理负担增加、维持亲子合作与伴侣分离都可能并存。能力线索只放在能力层，不能一边注明在职未知、一边仍靠它把在职排在无业之前。若功能条件确有区别，保留主要倾向和最强反向，不要求专属星象；身份或完成状态另判。未知不是否定，也不支持默认在职、已婚或已取得学历。

### 难分时，补什么、何时完成

先定位缺口，再做能改变判断的工作；不要把尚未分析称作无法判断，也不要反复算同一关系制造确定感。

| 当前缺口 | 补充动作 | 完成后的判定 |
|---|---|---|
| 四柱、目标大运、相关年份或边界未落实 | 用本地计算补齐该范围；固定时辰与校时约定不随解释改动 | 重建实际受影响的十神与主链，不只增加备用盘名单 |
| 支持与损害只列名称，尚未裁决 | 回到 `inference.md` 第四节，对同一瓶颈复核节点、通路和剩余作用；有中介时把直接作用与转化路径一起审 | 指出哪段可用、哪段受限，以及条件改变后主次如何转向 |
| 只有泛主题，目标宫或阶段尚未读 | 读取所问领域；符合主文件合参条件时，实际排紫微并独立审适用宫位和岁限 | 只采用对当前竞争表现增加区别的部分，不因补盘完成就改判 |
| 缺的是当前在职、已有伴侣等现实条件 | 普通咨询可补问会改变主判断的一项背景，其余分析先完成；用户要求直接答或不可补问时采用必要情景 | 不索取待预测事件或标准答案作为“补证据”；可判断进程，未给事实保持未定 |

当相关计算和可作用路径已审、补充只剩同义主题或不可取得事实时，交付当前最有依据的判断及限制。具体咨询仍须回答所问；选择题按 `exercise-mode.md` 给完整首选，并明确是相对倾向还是无区分的猜测。此步骤提高分析完成度，不承诺增加预测准确率。

### 应期：基础、承接与触发共同判断

- 原局指出长期依赖和瓶颈；大运改变能否发挥的条件；流年决定当时新增的变化。不能跳过大运承接，只挑最显眼的冲合。
- 对持续数年的主题，区分条件开始改变、能够推进、落实或终止。一个年份可能只提供机会，另一个才改变持续性；没有足够区别时给窗口，不伪造具体月份。
- 先固定所问阶段，再将各候选年放回各自实际所属的大运及相关区段，用同一标准比较，简记各年的“新增作用、所达环节、仍在的支持与牵制”。双事件分别排序，例如初次接触与关系落实不能由同一处宫动包办。优先年份的理由须相对最强竞争年成立；只找到更强烈或更多的符号时，仍按共有主题处理。
- 对各时段同查作用、反向及剩余支持；具体路径见 `inference.md` 第四、七节。压力与改善都须到达所问环节，不能前者直接决定终局，后者永远只是附带救应。
- 交运、换日或跨节若改变关键路径，按实际边界分段；只影响非关键节点时说明主判断为何仍成立。计算锚点不是事件日期。
- 已知背景用来缩小表现范围，不用于倒改命盘或喜忌。出生不确定时用已知事件校时，须另有独立事件检验，不能将同一事件解释通当成校时证实。

## E-REL：婚恋关系如何推进或终止

固定配偶角色和关系位置，方法见 `question-analysis.md`；紫微看夫妻宫及相关三方、岁限。先判断相处结构，再判断当时支持哪一阶段。

| 阶段 | 需要解释的新增条件 | 最强竞争表现 |
|---|---|---|
| 相识、约会 | 接触机会与关系主题能够结合 | 工作交往扩大、短暂吸引 |
| 稳定关系 | 相处、责任与资源有持续承接 | 机会很多但难以维持，或异地反复 |
| 承诺与共同生活 | 关系承接加强，生活及共同责任安排同步改变 | 同居、订婚、共同购房；不一定领证 |
| 登记或公开仪式 | 比较承诺落实与公开家庭安排的区别，保留实际制度日期未知 | 婚宴、登记、聚会可分属不同年份 |
| 分居或分手 | 共同生活或互动持续性受损，维系路径与救应不足 | 搬迁、出差、照护导致暂时分离 |
| 法律离婚 | 在已有婚姻或明确条件下，比较关系终止及事务安排 | 冷淡、争执、分居；无法据盘确认法律状态 |

关系体验、伴侣是否换人、共同生活安排与法律状态分别承接。后一期有支持，先问它支持当前伴侣互动、照顾责任还是新接触；支持尚存不证明未曾分离。未给婚育状态时，不先默认已婚再只比较婚年，也不由夫妻或子女角色存在排除尚无婚育；在观察范围内保留相应条件情景，仍给关系进程的主要倾向。

## E-EDU：学习资源怎样转为成果

| 阶段 | 要审查的通路 | 常见混淆 |
|---|---|---|
| 学习方式 | 印的支持到达日主，食伤能够整理表达；两者相互帮助或牵制 | 印多等于高学历，食伤多等于考试好 |
| 考核机会 | 学习承接之外，表达与制度评价有新增作用 | 工作考核、曝光也能解释 |
| 入学与持续修读 | 新环境、持续投入和学习支持能衔接 | 旅行、短训、搬家 |
| 完成课程 | 既有学习过程的延续、考核产出及阶段交接 | 只有入学机会，没有完成依据 |
| 入职 | 岗位、组织或客户承接发生独立变化 | 取得资格或毕业仍不等于已经就业 |

区分能力方向与现实已完成的学位。学制、入学和职业背景若已知就直接使用；未知时保留与本问题有关的限制，不能推导辍学、低智力或博士学位。观察时点决定当前阶段，不把未来潜力写成已经取得的结果。

## E-FIN：财源、承载与留存

| 所问指标 | 作用链应覆盖 | 要比较的反向条件 |
|---|---|---|
| 收入、营业额 | 技能或交易来源→财务承接 | 有机会但无法交付、有营收但回款不足 |
| 可用现金 | 收入回收→同期支出、融资与偿债 | 借款增加现金同时增加负债 |
| 净资产、财富阶段 | 财源→留存→资产与负债变化 | 买房增加资产也可能增加按揭，规模不等于净值 |
| 经营损失 | 已有经营或明确经营情景下，检查受损环节 | 合作分配、购置资产、照顾家庭也会花钱 |
| 外来支持、代偿 | 固定资金来源、承担责任者及受益对象 | 比劫或家庭宫位不能单独识别借款人、遗产或赔偿 |
| 居住与房产 | 财务来源去向与家庭居处安排分别审查 | 搬家、装修、按揭、产权取得互不等同 |

先区分扩大财源与改善承受能力：前者若增加负荷而救应未跟上，收入机会与资金压力可并存；后者若没有新财源，只能支持运作或留存改善。不能把两者都概括为暴富，也不能由流出直接定净损失。

金额、币种、资产套数没有五行换算标尺。可以形成财务方向及阶段判断，具体量级未定不等于所有年份完全一样；传统解释也不构成现实投资指令。

## E-WORK：工作依靠什么，改变了哪一环

依 `question-analysis.md` 判断组织资质、技术输出、客户交易和资本责任的主要路径，再看大运流年如何改变它。

- 职责及组织认可增强、现金路径没有同样变化：优先解释考核、评价或责任；不补写已经加薪，也不反证没有加薪。
- 产出、客户与财务承接增强：优先收入或业务机会；分别说明受薪、经营情景，食伤生财本身不能唯一指定创业。
- 旧职业依赖受损且有新路径承接：解释岗位、合作或工作方式调整；新支持未形成时，稳定性压力更值得关注。
- 比劫合作能形成资源与分工时可帮助交付，同时检查分配是否损害留存；不将竞争直接等同诈骗或合伙失败。

比较当前工作状态时，检查岗位、客户、交付及收入的实际持续条件；原局能力可用与当时在职是两层，缺乏失业判据也不是在职正证。职业内容、机构属性和权益身份的进一步比较见 `question-analysis.md`，不由工作方式直接补造当前职位。

## 主判断的表达与范围

将区别改写成不含星名的现实变化再核对一次。例如“责任增加”仍可能是升职或负担；“资源增加”仍可能是工资、贷款或出售资产。若核心区别未解决，就明确到这一层，而不是用更复杂的术语遮住缺口。

按所问子项说明依据，通常一句即可，不把整份咨询强制归为单一把握等级：

| 依据状态 | 如何表达与使用 |
|---|---|
| 某个方向、阶段或年份有相对区别 | 给该项的主要倾向、最强竞争及改判条件；其他细节未知不抹掉这项区别，也不继承它的支持 |
| 有相容线索，但未区分核心结果 | 说明倾向来自哪些命理线索、仍为何难分；用户要求单一结果时标“猜测：线索未分出优劣” |
| 完成补查仍无与该细节相关的可用线索 | 直说该细节没有可用判据；必须单选时标“猜测：无区分依据”，不补写貌似命理的理由 |

这些类别描述本次依据，不是准确率等级。标“相对支持”前，再核对它究竟区分了哪个子项和哪一个竞争表现；仅与首选相容仍属共有线索。局部有区别、核心结果并列时同时保留两层状态。评分保持事前类别，不能把方向判断错误一律归咎于精确细节，也不能把猜中升级为有效规则。

给主要方向时附最重要的反向条件，不要求先拿到完整传记才准许判断，也不把未知当成否定。冲合、宫忌等压力解释不能诊断病种、指认犯罪、推定敏感身份或预测寿限；按主文件和领域边界处理，已给事件的历史讨论仅在已知条件内进行。

两系统合参仍比较同一对象、阶段、时段。各自的共同主题不能互相充当独有证据，不能用同票升级事实确定性。普通咨询的这些判断用简短底稿保留；结构化评测和最终字母规则见 `exercise-mode.md`。

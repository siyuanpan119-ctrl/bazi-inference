# 事件辨别卡：把传统结构推进到可回答的层级

本篇由 AI 在解释具体事项、候选年份或复合选项时使用；普通用户仍只需出生时间、性别和出生地，不需要填写卡片或做评测。先完成原局及岁运，再选本篇相关的一张卡；没有具体问题的整体解读不必逐卡展开。

下表各项“允许的结论、停止升级、另需前提”说明证据能支持的解释范围，不取消最终选择。缺少真实入学、婚史、资产或债务来源时保留未知，题目答案仍按主文件及第九节交付并标把握。

## 先区分三种依据

| 依据 | 怎么记录 | 能支持什么 |
|---|---|---|
| 计算事实 | 四柱、根、藏干、实际宫位、四化层及日期区间，附底稿位置 | 证明某个符号关系确实在采用的盘中存在 |
| 传统框架 | 来源 ID、章名、原文或注者层次、适用前提 | 说明所用取法来自哪里；不证明人生事件已发生 |
| 操作假设 | 本文卡号、条件、竞争解释、会使结论撤回的观察 | 把传统框架用于现代问题；未经独立验证不称有效预测规则 |

本篇卡片均为**操作假设**，不是古籍原句或已校准概率。基础来源为 `knowledge-sources.md` 的 `TXT-ZPZQ`（配合及救应）、`TXT-DTS`（源流与承接）、`TXT-SMTH-DY`（原局后岁运），以及 `ziwei-inference.md` 所列《紫微斗数全书》卷三（三方支持与牵制）。这些来源不提供“某星等于结婚证／大学毕业证／银行入账”的一对一公式。

## 所有卡共用的检查方式

每个重要候选保留六行简短底稿，无需原样向用户展示：

1. **目标**：主体、事项、阶段、起止时间及观察时点；例如“本人、婚姻、登记、某公历年”。先列本题实际需要区分的维度，所有候选沿用同一组；不用一般机会或吉凶替换具体完成阶段。
2. **事实**：用户已给事实；必要但未知的现实前提标“未知”。不得用上一题的猜测、年龄常识或已知答案补成事实。
3. **结构**：引用原局主链，以及大运/大限、本年实际改变的节点；紫微须有目标宫、三方四正、叠宫和三层四化底稿。
4. **阶段条件**：逐项标“结构支持／现实已知／未知／存在反向结构／与已知事实冲突”。缺现实前提不等于事实不存在。
5. **区别**：与最强备选相比，新增的是哪个条件？若只重复“关系动、财动、宫有忌”，只记共有背景。
6. **结论范围**：提交最终首选，分别说明已支持的主题与仍未知的事件细节；难分题标猜测。附最强备选、反证和敏感命盘分支，不以底稿未决代替普通答题答案。

“成立”只用于已经核验的传统作用链，不用于宣布事件发生。缺少反证不能补成正面依据；一项支持也不能填满复合选项中的其他未知事实。计算资料缺字段时读取原始输出或补算，不能凭记忆填宫位、四化、干支或大限。

### 实际裁决：从共同主题找不到唯一事件时

先把每个选项拆成最小事实，比较全部候选，然后说明首选与最强备选的差异。将真正决定选项区别的维度写入 `target.facets`，逐候选记录 `facet_reviews`。例如职业复合题分别比较学历完成、工作方式、行业；意外收益题分别比较是否取得、来源、量级。若所得依据只说明一般输出或资源变化，该维度标共有背景或未知，不能声明具体事件已有相对支持。长选项不能因包含更多可联想的年份或角色而获得更多支持；缺少某子句的依据标未知，不作为该子句的反证。

完成逐项比较后保存一份允许并列的全候选排序，再确定最终选择及主要对照。对每一层先后说明实际依据；没有区分依据就并列，不以编造分数或任意权重强行拉开。首选落在并列组内时仍交卷并标猜测。共同背景只写一次，各项引用后写自身差异或无法区分的原因；重复文字只是复核提示，不能为了避免重复创造不存在的证据。

对所有候选填写相同的支持、反证、未知及最强竞争解释，再产生排序。已存在的首选也要重审；隐去“基线”“八字推荐”“紫微推荐”等身份后，判断标准不应改变。必要时轮换展示顺序检查位置偏好，按选项含义还原，不能因位置变化偷偷换事实。

例如一项为“完成课程”，另一项为“没有完成课程”：只有学习机会或文书象时，两项的完成状态均未知；未找到毕业证据不能反向证明未毕业。类似地，未证实创业不是已证实受薪，未识别重大疾病也不是已证实平安。相对支持可以形成排序，但不等于排他证明；不能只向新答案要求现实确证。两项都缺区分时，仍按答题要求给一个标明猜测的最终首选，同时停止提高事实确定性；不把选项较短、较普通或原先已经选中当作命理优势。

| 容易跨越的层级 | 应继续判断什么 | 停止升级的位置 |
|---|---|---|
| 机巨、昌曲、印或食伤 → 大学、健谈 | 分别检查吸收、考核输出与交际情境；口头表达、书面分析及喜欢社交不是一项能力 | 学习/表达方式不能替代已完成学位或实际社交习惯 |
| 夫妻受动、财官出现 → 已婚/离婚 | 区分机会、承诺与法律状态；对象和时段一致后再比较 | 不用某年的关系窗口回填多年后的婚姻事实 |
| 迁移受动 → 因留学分手 | 迁移是环境主题；留学、旅游、调职和异地仍须分别鉴别，分手原因另需关系主线 | 迁移动象不作为“留学导致分手”的排他条件 |
| 财禄或食伤生财 → 经营、多套房、巨额横财 | 先看受薪/经营、取得/留存、收入/资产；财富来源与金额分别留条件 | 无币值和产权标尺时，不按“承载力”划千万、过亿或几套房 |
| 冲刑或伏吟 → 事件发生年 | 各候选年都比较对象、阶段、承接与救应；变化幅度和事件类型分别判断 | 最强冲动不能自动赢过阶段更贴合但变化较弱的年份 |

这些是对解释跳步的限制，不是弃答条件或新命理定律。只有规则前提、作用对象、事件阶段、对其他候选的区别都记录清楚，才可标“有相对区分依据”；否则提交的字母标为猜测，底稿记强制排序。两套体系都出现上述同一跳步不能互相补足。

落地格式与检查命令见 `decision-record.md`。记录中每条依据分为共有背景或声明的区分条件；检查器只能发现显式缺口，不能确认一条自然语言联想真的具有区分力。

## E-REL：婚恋机会、落实与终止

先固定配偶角色取法及关系位置；八字依 `question-analysis.md` 第五节，紫微依夫妻宫的完整三方四正和岁限。下表的“另需”是对所答阶段的要求，不把社会常识伪装成命盘条件。

| 阶段 | 在前一层之外另需比较 | 最强竞争解释与反证 | 允许的结论 |
|---|---|---|---|
| 相识／约会机会 | 接触或关系主线新增条件，且未被职业社交解释同样覆盖 | 只有工作往来；机会出现但关系承接受限 | 接触机会增加，不能确认有对象 |
| 稳定交往 | 机会之外，持续相处、资源与责任承接均有支持；已有关系可由用户事实确认 | 短暂吸引、异地或相处反复；支持仅在很短时段出现 | 较利关系建立或维持 |
| 登记 | 关系基础加共同责任与制度安排两条可区分的结构；关系基础未知须保持条件句 | 同居、订婚、共同购房也能解释；只有日支合或夫妻宫动 | 可列承诺落实窗口；不能由盘确认领证 |
| 婚宴／公开仪式 | 关系落实之外，公开活动、亲友或家庭安排有不同于登记的线索 | 家庭聚会、工作曝光；仪式可晚于登记甚至不举行 | 仅在有额外区分条件时另列仪式候选时间 |
| 分居／分手 | 既有互动或共同生活安排承压，维系支持受损，替代解释比较后仍偏关系持续性 | 工作搬迁、暂时分离、照护责任；救应仍可维持关系 | 若已有关系，持续性压力或分开候选 |
| 法律离婚 | 必须区分已婚事实与其法律终止；比较关系及制度安排压力 | 争吵、分居不等于法律终止；没有已婚事实 | 历史题可给年份候选并标猜测；不把选择写成已核实法律事件 |

同一流年不能因财官透出同时“证明”相识、领证、生育。若题目把三者写进一个选项，每一阶段分别留支持和未知；登记与摆酒相隔一年也不得合并判对。没有婚史时至多提供“单身／已有伴侣”两条短分支。

## E-EDU：能力、入学、结业与就业

| 阶段 | 必查条件 | 撤回或降级条件 |
|---|---|---|
| 学习能力／方式 | 印的支持如何到达日主，食伤输出是否可用；紫微命、官禄及文书组合如何承接 | 只数印或昌曲、化科；把学习偏好等同成绩 |
| 申请／考试机会 | 学习支持之外，考核表达与制度认可有本年新增条件 | 只有环境变化；化科同样可能是工作评价 |
| 入学 | 新环境与持续学习的承接，而不只是考试曝光；已获录取可作为用户事实 | 旅游、搬家、短训也吻合；现实入学状态未知 |
| 完成课程／毕业 | 原有学习过程有延续，产出与考核完成有支持；已知入学时间或学制才用于排除不可能时间 | 只有印运、新科名主题或转工；不能倒造入学年 |
| 就业／入职 | 岗位、组织或客户承接发生独立变化；与毕业分别判断 | 考取资格仍未入职；就业机会不等于已签约 |

观察时点决定“当时已完成的学历”，与未来潜力分开。用年龄、学制排除选项时标为现实约束；例如年龄使博士不合常态并非命理命中。不能从现代学位高低回填善恶、智力或家庭富裕程度。

## E-FIN：流量、存量与责任归属

| 目标 | 结构比较必须覆盖 | 竞争解释／不得补齐的环节 |
|---|---|---|
| 收入／营业额 | 技能或交易来源→财务承接；明确受薪或经营情景 | 有订单不等于回款，有营收不等于利润 |
| 可用现金 | 收入承接→回收→同期支出及偿债；分别说明机会和占用 | 融资使现金增加同时负债增加；不得只见禄或财就称发财 |
| 净资产／财富顶峰 | 流量之外，留存、资产与负债各有比较；题目各年使用同一指标 | 买房可增加资产和按揭；规模扩大不等于净值最高 |
| 自己经营亏损 | 自身经营或投资环节承压，需要已知相关活动才指定原因 | 合作分配、照顾家庭、购置资产也会耗资 |
| 为他人代偿／资助 | 除财务流出外，必须有独立、已固定对象的责任链；本人负担与受益对象分别记录 | 比劫、父母宫或田宅宫单独受动不能识别借款人；无现实债务来源时不指定“家人还债” |
| 房产交易 | 财帛的来源和去向与田宅／家庭安排的不同条件同时核验 | 搬家、装修、按揭、买卖各不相同；不能把“田宅动”当产权登记 |

分歧处理例：财务压力主题较明显而责任对象没有独有证据，事实论证应停在“现金或责任负担增加，来源未能区分”。题目要求从赌博、诈骗、代偿中选择时，按第九节区分历史作答与现实指控，适用的练习仍给标为猜测的首选；不得把故事合理性当成独有命理证据。精确币种和金额没有命盘换算公式。

## E-WORK：组织认可与现金回报

先看工作依赖的是组织资质、技术交付还是客户经营。原局和岁运的主链必须有实际节点，单见官印、武曲或紫微均不足以确认岗位。

- 组织职责／文书认可新增而财务承接无独有改善：优先描述评价、考核或职责主题；不能断言“实际获奖但没有加薪”。
- 产出、客户与财务承接都增加：可相对优先收入机会，仍区分薪资、营业额和净收益。
- 旧工作依赖受损同时新承接存在：优先工作安排变动；新承接尚缺则描述稳定性承压，不自动升级为开除或失业。
- 自主经营路径完整且现实已有经营活动：解释经营进展；活动未知时保留岗位管理与创业的竞争。官禄有权不等于老板，某五行不等于特定行业。

比较受薪与创业时，对两项分别核查工作组织、客户与交易、资本责任这几个不同环节。食伤生财能描述技能换取工资，也能描述经营收入，单凭这条共有链不能优先创业；同样，缺少创业事实不能自动确认打工。

## 不宜细分的事件与题目陷阱

- 不把健康压力线索当成器官病变、手术结局、致残或死亡的临床依据，也不把星宫当真实个人属性识别器。按 `question-analysis.md` 第九节识别任务；历史题仍比较候选并交付适用的选择，不能以本条作关键词弃答开关。
- “哪件事没有发生”要分别审查存在与不存在。没有结构支持不是没有发生；若无明确事实排除，普通题仍提交标为猜测的首选，不能声称已经识别了不存在的事实。
- 极罕见职业、宝藏故事、特定国家身份、神明报号码不是普通主题线索能推出的细节。不得因已知答案才增设专门口诀。
- 常识明显排除某个选项时，记录 `现实/常识排除`，与 `传统结构区分` 分开。只凭常识得到答案不宣称来自命理，缺少其他选项的医学或犯罪证据也不是选中某个普通选项的正面命理证据。

## 跨系统如何使用本篇

八字与紫微各自完成同一卡，不互相借用结论填未知字段；然后按 `ziwei-inference.md` 的融合表比较。只在同一主体、同一阶段、同一时间段内比较新增条件。两系统若一个解释相识、另一个解释婚宴，应拆成不同阶段，而非判成互相矛盾或互相印证。

用户提供过去事件可帮助缩小未知前提，但它始终标为已知事实。由已知事件选择时间分支属于校时假设；若没有其他独立事件检验，只能报告该分支与已知事件相容，不能宣称出生时刻已证实或预测准确率已提高。

# 命局、大运与年度报告

## 按用户请求决定篇幅

用户只问一个年份的一件事，就直接回答那件事，不扩写整个人生。用户只给出生资料要求算命，默认给命局主线、事业财务、性格关系、当前大运与年度概览；不先要求用户交代完整生平。用户要求年度报告时使用本文件。时区/日期/时辰缺失且会影响命盘时只问必要问题，其他分析先完成。

说明一次采用传统八字框架和计算口径即可。主要篇幅用于判断与依据，不逐段重复免责声明。

## 计算和阅读资料

运行 `scripts/report_engine.py`；最小输入与 CLI 见主文件。默认报告年度为 `--as-of` 所在年；多年用重复 `--year`。用户明确观察年份或区间时优先采用，不擅自取年末作为已知时点。把输出当事实底稿，再依 `inference.md`、必要的 `patterns.md` 和 `question-analysis.md` 形成解释。

对关系、学业、财务或工作等具体阶段，使用 `event-discrimination.md` 对应卡片：只读需要的卡，不把整份检查表展示给用户。报告的主题趋势与已发生事实分开，结构相容不能写成既定传记。

“某年开始至今”要先明确观察终点，再列这段时期相交的全部大运。逐段分析延续、转折和恢复，不能只取首年的一条关系代表十几年。年份精确而月份未知的交运年，同时比较前后两段；某条件只存在于其中一段，就不能称为贯穿整年的判断依据。

| 计算字段 | 应怎样用 |
|---|---|
| `chart` | 复核四柱、十神、藏干、时间口径和边界状态 |
| `dayun` | 使用实际起止区间，确定当前、前一、后一运 |
| `annual_reports[].dayun_segments` | 把交运年拆成相应阶段，不凭整数年龄套运 |
| `annual_reports[].annual_natal_relations` | 读取涉及流年的关系，再与原局及大运对照；区分原有关系重现与实际新增作用 |
| `months[].dayun_segments` | 看原局＋大运＋流年＋流月联合关系，跨交运月份仍分段 |
| `traditional_observation` | 仅作粗主题提示；不能原样复制便称完整命理判断 |

`--markdown` 只导出计算底稿，不自动写成最终年度报告。无执行能力时允许以已核验命盘分析，明确未复算项。

## 先形成一份稳定的原局摘要

在分析任何年份前，固定以下六项，写成一小段或工作表：

1. 日主在该月令是否得时，主要根气和生扶在哪里。
2. 主要泄耗制约是什么，日主能否承接，最强反向依据是什么。
3. 所取格局、用神、相神；对应干支位置及实际成格条件。
4. 哪个条件最易受损，原局已有的救应是否有效。
5. 格局、扶抑、调候三栏怎样协调；若相冲，按问题说明主次。
6. 一句贯穿各年主线，例如“输出能生财，但承载和印的支持决定增加的资源能否留住”。

主线来自实际命盘，不能把这句例子复制给所有人。后面的某个年份改变的是这条链的条件，不是让你另选一套完全相反的喜忌。用户已给职业、婚史或生活阶段时，以此固定事项对象，新增判断集中于方向、持续性和时间窗口；已知背景不算本次新预测。

普通年度分析用简短工作底稿保留“对象与阶段—原局主链—该运新增—该年新增—反向条件—主判断”即可。只有涉及实际边界时才另列分支；无需创建逐题 JSON、答案排序或运行选择记录检查器。

## 判断一段大运

按下一套顺序完成，结果必须能解释“这一运相对上一运变在哪里”：

1. 运干以哪个十神参与；运支给谁根气、藏气或冲合对象。
2. 它补足了原局的哪个必要环节，还是把已有环节加重；对关键救应有何影响。
3. 先写原局主链的变化，再写与问题相关的生活主题。
4. 比较同一条件在前后大运是否存在，决定相对偏向；多年区间与运界不一致时，分别覆盖主要阶段和转折。末段变好先表述为后期改善，不借此替整段财富或关系下结论。
5. 若正向和反向作用并存，明确哪个是当前主限制、什么前提会使另一作用占上风。

输出表可用：

| 区间与大运 | 比上一阶段新增的条件 | 主要传统判断 | 何时需要改判 |
|---|---|---|---|
| 采用计算区间 | 写具体干支与作用对象 | 回答事业/资源/关系主题 | 写最强反向条件 |

通常只展开当前和相邻两运；用户要完整大运才展开全部。遥远年份不预测寿限，也不假定此人届时一定担任某职业、结婚或有子女。

## 判断流年，不把大运与流年分开念

把流年加入当时大运和原局，依次判断：

- **维持**：原局的关键环节没有实质变化，优先考虑延续，不硬造转折。
- **补足**：流年提供原先缺少的根、印、制化或承接；若相应现实活动存在，优先考虑该领域更容易落实。
- **削弱**：流年损害主链或救应，优先考虑该环节的制约加重；具体是资源、职责还是关系，要回到所问事项。
- **并存**：一边补助、一边加压，分别写作用对象，再给有主次的判断；不能以“好坏都有”结束。
- **改组**：关键根气、完整会合或制化关系实质改变，重查成格/从化条件；不因一个冲合标签就宣告换格。

这些是本技能的组织方法，不是古籍原句或经验概率公式。按 `question-analysis.md` 将结构与所问事件相连。比较年份时，说明各年改变了哪一环、哪个阶段更容易落实；共有背景不构成年份差异。只有月份或具体金额难辨时，保留已有年度方向，不把整项退成“有变化”。无法区分相邻年份时可给连续窗口，并说明暂不能再收窄。

公历元旦到立春前仍属上一流年。用户问“未来一年”，按起止日期分段，不偷换成单一干支年。起运约日受出生和计算口径影响时保留边界，不把某一天当作人生事件开关。

加入紫微时按 `ziwei-inference.md` 分别形成各自底稿后合参。全年分析读取目标宫、三方四正、本命／大限／流年四化和叠宫，覆盖实际采用年界与大限变化；某个代表日快照不能代表公历全年。两系统时间边界各自保留，最后对齐同一实际日期段、对象和事件阶段。方向相容不按票数提高把握，冲突则检查各自前提并说明最终主判断与仍存的竞争解释；不以任意权重掩盖分歧。

## 年度报告的交付顺序

### 1. 先回答全年重点

用两三句话说明本年主要倾向、相对有利方向和最主要牵制。例如“本年更偏向通过既有能力取得成果，但资源分配会影响实际收益”，随后说明是哪条命局与岁运链支持它。无相应依据就不要套用。

### 2. 列命盘与主线

四柱、日主、必要十神与藏干用一张小表。附出生信息处理、用神相神、扶抑调候和当前大运，重点解释主线，不逐字罗列所有神煞。

### 3. 回答各生活领域

| 领域 | 如何形成主要判断 | 必须区分 |
|---|---|---|
| 事业与学习 | 官杀要求能否经印承接；食伤输出有无去处；适合维持、准备、展示能力或推动变化的相对倾向 | 责任增加、被认可、升职、换工作是不同结果 |
| 财务与资源 | 财的来源、流向、承载及支出如何改变；倾向稳步积累、经营活跃还是负担增多 | 机会、营收、到账、净收益、资产存量分开 |
| 婚恋与家庭 | 看固定的星宫取法及整体配合；关系安排较易落实还是受牵制 | 单身/已有伴侣分别解释；相识、登记、分居与离婚分开 |
| 性格与生活节奏 | 从主链说明常见反应模式、表达和决策的长处及制约 | 原局倾向不等于每种场合的固定性格或医学判断 |

每项使用“主要判断—原局及岁运依据—竞争解释/改变条件”。主要判断应具体到已获支持的生活进程，例如职责扩大、交易更活跃、留存承压或关系更易落实；不要只写“官财变化”。先区分来源改善、能否承接、最终结果与代价，再定主次。实际背景未知时，给最少必要分支，不让用户先回答一份长问卷。具体事项的判断方法见 `question-analysis.md`。

### 4. 需要时细分流月

先确定全年方向再细分，最多突出少数有实质区别的时段。十二节月用实际节气界限；完整月表或按季节合并均可，合并只是摘要。

把相关月份的大运、流年、原局一同纳入；某个冲合重复出现只说明同一作用持续或加强的假设，不能当成几份独立事实。若月度细分不能增加辨别力，直接保持年度层级，不制造精确到月的假象。

### 5. 以有针对性的说明收尾

给少量对应主要制约的建议：例如职责标准、合作分配、回款安排、学习准备、关系沟通。明确这类建议来自一般现实判断，不能凭命理结果要求用户做投资、医疗或法律决定。

可以附两三项有明确含义的观察点，方便用户理解本次判断指什么；不要求用户参与评分或长期实验。用户要短答时省略观察表。

## 输出前最后核对

- 首段是否回答了用户实际问题，而非只展示计算过程？
- 每个主要判断是否有原局作用链及对应岁运变化？
- 是否说明为什么优先这一解释，而不是另一种同样可能的表现？
- 是否把“透”与“藏”、用神与扶抑调候、十神与现实身份混淆？
- 是否把不知道的生平、精确金额、病名或严重事件编入报告？
- 主要结论会不会随时间口径分支改变；若会，是否写清？
- 具体事项的对象、阶段与用户所问是否一致，用户已给事实是否被正确作为条件？多个年份或必要分支是否实际比较主链变化，而非复制总述？
- 合参是否实际读取大限四化、目标宫及三方，且双方判断曾各自完成？顺序分析是否如实说明其局限？

只有结构标签、通用建议或免责声明的输出不算完成。应给出明确的年度主判断、优先时间窗口及必要条件；具体细节未知不一并抹去已支持的方向。用户明确做命例选择或评分时，另读 `exercise-mode.md`，其答卷和检查流程不作为普通年度分析的前置条件。

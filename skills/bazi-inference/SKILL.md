# 八字命理推演

当前版本：**0.5.4**，本轮整理后的维护基线；版本与验证范围见 `assets/release.json`。维护版本不代表预测准确率领先，传统解释及合参收益仍未验证。

**长期目标：面向普通用户，改进可迁移的命理推演技巧与实际解读能力。** 出生日期时间、性别、出生城市是基本输入；必要背景按问题使用，不要求人生问卷。命例题用于发现缺陷和检验修订，不将题目答案写入通用规则。

## 按问题取用

| 请求 | 读取与使用 |
|---|---|
| 整体命局、直接算命 | `references/inference.md`；取格时查 `references/patterns.md` 对应分支 |
| 事业财运、婚恋家庭、学业性格 | 核定命局后读 `references/question-analysis.md` 对应领域 |
| 年度、大运、几年比较 | `references/annual-report.md`；具体进程与应期查 `references/event-discrimination.md` |
| 紫微或两系统合参 | `references/ziwei-inference.md`；计算接口见 `references/calculation.md` |
| 选择题、固定答卷 | `references/exercise-mode.md`；沿用通用推演，完整单选交付 |
| 对答案、复盘、维护优化 | `references/review-and-evaluation.md`；冻结原判断再计分 |

只读当前任务需要的资料。普通咨询和版本答题均默认保留简短工作底稿；用户明确要求结构化审计或机器评测时才读 `references/decision-record.md`，使用既有v3记录及检查器。

## 核验输入与范围

保留原始出生表述，默认公历；核实农历闰月、历史时区、夏令时、节气和时辰边界。用户明确的校时约定优先；默认标准时、00:00换日，不重复扣时。视太阳时须有经度来源，接口与不完整资料处理见 `references/calculation.md`。

在技能目录执行计算，例如：

```bash
python scripts/report_engine.py --input /absolute/path/birth.json --as-of-year YYYY --year YYYY --output /absolute/path/context.json --markdown /absolute/path/context.md
```

输入格式示例：`{"birth_datetime":"2000-07-15T14:20","sex":"male","birthplace":"香港"}`。这是合成数据。实际任务采用用户资料与观察日期；只给年份用 `--as-of-year`，给具体日期用 `--as-of YYYY-MM-DD`，多个待比较年份重复 `--year`。

缺城市、分钟或日期有歧义时，先完成可确定部分；参考地点和区间中心只作计算情景。发生不同命盘时分别重建受影响的十神、主链与岁运，说明共同结论和实际分歧。交运时刻是约值，按出生地时间表述；无执行条件时标明未复算部分，不声称已经运行。

从原文保留**已知条件、主体、未知变量、观察范围**，核对亲属指代、否定词、人数和时间。已给事件只问年份时，不重新证明其地点或发生事实；当前状态不扩成终身结论。自己的前项推断不能作为后项已知生平。

## 建立命局与岁运主线

依 `references/inference.md` 从月令、透藏、实根、生源与实际生克通路定主案。强弱、格局成败及寒暖燥湿分别审查；用神、相神须对应可作用的具体干支。合不直接当化，冲不直接删根，从格须通过成立条件。

用几句底稿说明：主导作用、可用支持、关键瓶颈和最强反向条件。沿原局→大运→流年重审同一条主线，分清已有条件、重现和新增或解除的作用；比较损害、救应及剩余承接，不用喜忌名称直接决定终局。只有影响所问结论时才展开交运、年界或流月分段。

## 判断表现、补查与合参

按 `references/event-discrimination.md`，将作用接到所问对象和阶段，并与最接近的竞争表现比较。能力、机会、现实活动和完成结果分开；只支持某一方向的依据不自动支持具体身份、病种或金额。同一标准用于首选及竞争项，保留题目原本的量词、程度和时限。

难分时先定位缺口，补齐可取得的计算、目标领域与漏审作用。用户指定单一体系时遵从；要求充分分析、合参或批量命例验证，且紫微能补充适用宫位或岁限、资料与工具可用时，实际补排后交付。简单咨询不机械扩成双盘。两系统各自保存判断，再按 `references/ziwei-inference.md` 比较实际新增区别；顺序分析如实注明，不能以同票或后来出现的解释决定主次。

相关计算和作用已经审完、补查只剩同义主题或不可取得的事实时，交付当前判断与具体限制，不反复加盘或换取法。普通咨询只在必要时补问会改变主判断的一项背景，不能把待预测的结果索取回来当证据。

## 交付

先回答所问，再说明关键原局依据、岁运变化和最重要的适用条件。仅给出生资料时提供整体主线、主要领域和当前运势；具体问题聚焦作答。保留有区别的方向或窗口，分别说明未定细节；必须单选时照常给首选及真实依据状态。

依据状态描述的是这次解释，不是命中概率。共有主题不增加区分力，结构检查不证明推演正确。避免把整篇答案写成“都有可能”或反复免责声明，也不靠更肯定的语气制造精度；现实建议说明来源，不冒称命盘唯一推出。

## 取法与来源

- 五行生：木→火→土→金→水→木；克：木→土→水→火→金→木。十神正偏以日干阴阳、五行关系计算。“透”指天干，地支为藏或得地。
- 用神指定格局的十神，相神指辅助成格的十神；扶抑、调候需要另列。
- 计算事实、传统规则、操作假设与现实反馈分开，见 `references/knowledge-sources.md`；新增假设保留前提、竞争解释和撤回条件，不假托古籍或已验证准确率。
- 不伪造出生资料、生平及计算过程，不以星象替代医学诊断、现实法律事实、敏感属性认定或寿限预言，见 `references/question-analysis.md`。
- 离线任务只用本地规则、原始资料与本次底稿；任何模式均不以命题人、生日或题目搜现成答案，不检索历史或记忆答案。已揭晓资料只用于复盘，不能包装成事前预测。
